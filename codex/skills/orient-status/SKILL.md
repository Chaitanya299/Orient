# orient-status

Report where the project stands, cheaply.

The docs directory is `docs` unless the user named a different one. Read
`<docs_dir>/STATE.md` and **only** that file. Answer in under 10 lines: current focus,
what's in progress, what's blocked.

If `STATE.md` is missing, say so and suggest the orient-init skill. Do not explore the
repo. Do not read the decisions. This skill exists to be nearly free.
